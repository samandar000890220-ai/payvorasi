===================

[chuckle]
[sigh]
[clear throat]
[cough]
[groan]
[gasp]

should produce actual audible vocal events rather than simply altering the emotion of the following sentence.

Build this as an extensible event system.

Example internal representation:

[
{
"type": "speech",
"text": "That is unbelievable."
},
{
"type": "vocal_event",
"event": "gasp"
},
{
"type": "speech",
"text": "I didn't expect that."
}
]
